# Base de datos

Carpeta reservada para los scripts SQL del proyecto.

- `schema.sql`: tablas, relaciones y restricciones, cuando se apruebe el esquema.
- `seed.sql`: datos ficticios de desarrollo, cuando sean necesarios.

Estos archivos todavía no forman parte de la base de `main`. La rama `US-01-02` tiene una propuesta opcional de esquema; su demo utiliza memoria y no necesita PostgreSQL.
